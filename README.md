# ICICI Bank Ltd. - Equity Research & Valuation

## Project Overview

This project presents a student-led equity research and valuation analysis of **ICICI Bank Limited**, with a focus on fundamental banking metrics and relative valuation.

The project was prepared for academic and placement-interview learning. A publicly available broker research report was used as a **reference for research structure and valuation methodology**; the analysis, scenario assumptions and valuation presented here are the student's own model.

## Objectives

- Analyse ICICI Bank's operating and financial performance.
- Study key banking indicators such as loan growth, deposit growth, NIM, GNPA, NNPA, ROA and ROE.
- Build a forward-looking earnings framework.
- Value the bank using **Price / Adjusted Book Value (P/ABV)**.
- Incorporate a separate value for subsidiaries.
- Test the valuation under Bear, Base and Bull scenarios.
- Develop an investment view and identify key catalysts and risks.

### Valuation

Because ICICI Bank is a bank, the primary valuation framework used in this project is **P/ABV** rather than a conventional industrial-company EV/EBITDA framework.

The model uses:

**Core Bank Value = FY27E ABV per share x P/ABV multiple**

Then:

**Target Price = Core Bank Value + Subsidiary Value per Share**

## Scenario Analysis

| Scenario | P/ABV | Subsidiary Value / Share | Approx. Target Price |
|---|---:|---:|---:|
| Bear | 2.25x | INR 200 | INR 1,358 |
| Base | 2.60x | INR 250 | INR 1,588 |
| Bull | 2.85x | INR 275 | INR 1,741 |

The base-case assumptions are independent student assumptions and are **not the broker's published target price**.

## Base-Case View
Using the model assumptions, the estimated base-case target price is approximately **INR 1,588 per share** versus the INR 1,418 reference price used in the model.

This implies approximately **12% upside**, leading to a **Neutral / Watchlist** investment view.

## Key Investment Drivers

- Sustained loan growth.
- Healthy deposit mobilisation.
- Stable NIM.
- Strong profitability and ROE.
- Controlled asset quality.
- Strong capitalisation.
- Potential value contribution from subsidiaries.

## Key Risks

- NIM compression.
- Higher credit costs or deterioration in asset quality.
- Slower deposit growth.
- Lower-than-expected loan growth.
- Compression in the P/ABV valuation multiple.
- Regulatory or capital-related changes.
